## ⚙️ التعديل والتخصيص (Configuration)
لتغيير رقم الواتساب أو معرّف InstaPay، افتح ملف `js/script.js` وقم بتعديل كائن `CONFIG` في بداية الملف:
```javascript
const CONFIG = {
  whatsappNumber: '201012345678', // ضع رقمك بصيغة دولية بدون + أو مسافات
  instapayHandle: 'husseinabdelrazek@instapay', // معرف انستاباي الخاص بك
  defaultLang: 'ar' // لغة البداية الافتراضية
};
```
لتعديل الأسعار، يمكنك تعديل القيم في `index.html` داخل بطاقات الخدمات والـ `<select>` في النوافذ المنبثقة بكل سهولة.

## 🚀 دليل الرفع على استضافة Hostinger (Deployment Guide)
الموقع مصمم ليعمل كـ **موقع ثابت (Static Website)** عالي السرعة، وهو متوافق بنسبة 100% مع جميع خطط استضافة Hostinger (Shared, Cloud, WordPress Hosting).

### الطريقة الأولى: عبر لوحة تحكم Hostinger (hPanel File Manager) - أسهل وأسرع طريقة
1. سجّل الدخول إلى حسابك في **Hostinger** وافتح **hPanel**.
2. توجّه إلى **Websites** ثم اضغط على **Manage** بجانب اسم الدومين الخاص بك.
3. افتح **File Manager** (مدير الملفات) وتوجّه إلى المجلد الرئيسي: `public_html`.
4. إذا وُجد ملف افتراضي باسم `default.php` قم بحذفه.
5. اضغط على أيقونة **Upload** (رفع) وارفع كافة محتويات مجلد المشروع:
   - ملف `index.html`
   - ملف `.htaccess`
   - مجلد `css`
   - مجلد `js`
   - مجلد `assets`
6. تأكد من تفعيل شهادة الأمان **SSL** مجاناً من لوحة Hostinger تحت تبويب **Security > SSL**.
7. افتح موقعك في المتصفح!

### الطريقة الثانية: عبر Git Deployment في Hostinger
1. قم بإنشاء مستودع GitHub خاص أو عام وارفع عليه ملفات المشروع.
2. في لوحة **hPanel**، توجّه إلى **Advanced > Git**.
3. ضع رابط المستودع وفرع `main` وحدد المسار `public_html`.
4. اضغط **Create** ثم **Deploy**.
